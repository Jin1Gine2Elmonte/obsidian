# Tool & Workflow History — Recovered Context

## Purpose
This file records durable remembered context about the user's practical tool/workflow history across writing, web, Android, AI, deployment, and knowledge-management work. It is a historical context owner, not a catalog of every tool ever mentioned.

## Core principle
Tools appeared in the user's work for different reasons. A tool name alone is not the important memory; the useful historical unit is:

`problem -> tool/approach -> what it enabled -> friction/failure -> what survived afterward`

## AI-model ecosystem
The user has explored and compared multiple model families and providers, including ChatGPT, Gemini, DeepSeek, GLM, Nemotron, Google GenAI SDK, and other generation tools.

The recurring evaluation criterion is behavioral usefulness in the actual workflow rather than name recognition alone:
- reasoning behavior;
- tool access;
- context handling;
- reliability;
- deployment feasibility;
- cost/resource constraints;
- ability to participate in a larger memory/agent architecture.

## Local-device experimentation
The user has explored local AI and development under constrained consumer hardware/Android environments as well as stronger hypothetical desktop environments. The durable design lesson is to separate:
- what is theoretically possible;
- what is locally feasible;
- what is economically practical;
- what is operationally maintainable.

## Cross-tool pattern
Across these tools, the same pattern recurs:

`interface != storage`

`model != memory`

`provider != project`

`deployment platform != architecture`

A tool can be replaced while the underlying intent, data, or project structure survives.

## Recovery boundary
This file intentionally does not claim exact dates, full command histories, benchmark results, or complete implementation states for every tool. Those require source-level artifacts or conversation evidence.

Where the historical source is missing, the tool is recorded as **recovered context**, not as a fully reconstructed implementation history.
