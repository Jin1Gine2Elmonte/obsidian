# Memory Graph

## Graph philosophy
The vault is a graph expressed through Markdown. Files are readable containers; links and relationships are the real structure.

## Graph traversal rule
When answering a project question, retrieve the shortest meaningful chain from the immediate task to its strongest anchors. Expand into neighboring nodes only when they materially affect correctness, continuity, or emotional meaning.

## Graph maintenance
Whenever a new anchor is created, add it here. Whenever an important relationship becomes explicit, record it here rather than leaving the relation implicit inside prose.
