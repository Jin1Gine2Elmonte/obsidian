### Surgical-edit principle
A recurring user requirement is that an edit must change the requested element without silently redesigning unrelated parts.
Protected elements can include:
- composition;
- character;
- city/background;
- sky color;
- global lighting;
- palette;
- typography;
- image dimensions.

### Strings of Fate visual history
High-confidence remembered constraints include:
- title: **أوتار القدر / Strings of Fate**;
- strings should be white and transparent or semi-transparent;
- emitted light should lean subtly toward light/emerald green;
- they should not become solid green strings;
- the glow must not recolor the sky;
- composition, city, character, overall lighting, and primary colors should remain intact unless explicitly requested;
- lower writing may be removed when requested;
- decoration below the title may be improved when requested;
- final dimensions should remain unchanged;
- the result should avoid an obvious generic AI-generated appearance.

A key visual idea is: **change the strings' light, not the world around them**.

### Manga/page continuity
The user's visual workflow has included sequential manga/page generation. A remembered failure occurred when a later page drifted toward a different visual language (including a Ghibli-like direction) instead of preserving the established page identity.

Durable lesson:
- visual continuity across sequential images is part of narrative continuity;
- later pages should preserve the established visual grammar rather than resetting style per prompt.

## Creative-tool workflow lessons
1. Preserve local constraints during edits.
2. Treat visual history as part of project history, not only as a collection of prompts.
3. Separate a visual reference from a canonical narrative claim.
4. Keep music/audio experiments distinct from fiction canon unless the user explicitly links them.
5. Preserve discarded visual directions when they explain why a later style was chosen.
6. Tool/model changes should not erase the underlying creative intent.
