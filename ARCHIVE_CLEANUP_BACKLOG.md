When two files mention the same event, each must answer a different question or one should link to the other.

## Tier 5 — future deletions / conversions
Potentially redundant files should be converted to link-only notes only after unique information is checked. No deletion should occur solely from filename similarity.

## Completion definition
Cleanup is complete for a node when:
1. one file clearly owns each knowledge type;
2. duplicates contain no conflicting current claims;
3. historical information is preserved where materially useful;
4. cross-references point to the owner;
5. a future update has an obvious place to land.

## Rule
This backlog must evolve by evidence. It is not permission to delete information merely because it looks repetitive.
