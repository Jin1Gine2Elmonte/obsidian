## Evidence / boundary layer

The detailed anchor files own their individual definitions. This README owns only directory navigation and the boundary between anchor identity and global cosmology synthesis.

## Preservation rules
1. A shared name does not prove shared cosmological continuity.
2. Thematic resemblance is not a canonical relationship.
3. Do not construct a hierarchy between anchors without direct evidence.
4. Project membership remains unresolved when source evidence is absent.
5. Recovery layers and synthesis must not silently become canon.

## Recovery priority
When original conversations or scene material become available, prioritize evidence that establishes:
- which project/generation owns each anchor;
- explicit relationships between anchors;
- cosmological hierarchy or causal structure;
- connections between the human/imperial and cosmic layers.

See `COSMOLOGY.md`, `NEGATIVE_KNOWLEDGE.md`, and `RECOVERY_EVIDENCE_PIPELINE.md` for cross-domain navigation and recovery rules.
