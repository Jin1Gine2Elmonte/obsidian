# Lesson Provenance Map

## Purpose
Connect durable lessons to the work, failures, corrections, and archive changes that justified them. This is not a second lesson list; it is the evidence/causal layer behind `DECISIONS_AND_LESSONS.md`.

## L-001 — Volume is not memory
**Observed through:** repeated archive expansion followed by user correction that added size without enough genuine information.
**Changed:** deduplication, ownership, consolidation, recovery-first policy.
**Prevents:** creating files whose only value is repetition.

## L-002 — Review before expansion
**Observed through:** repeated discovery that new files were duplicating existing knowledge.
**Changed:** canonical ownership map and cleanup backlog became mandatory maintenance layers.
**Prevents:** competing current truths and archive inflation.

## L-003 — Evidence beats elegant synthesis
**Observed through:** Jin/Ryota ambiguity and multiple version/project-generation possibilities.
**Changed:** canon/provenance model, conflict preservation, raw-evidence priority.
**Prevents:** turning plausible interpretation into canon.

## L-004 — Similarity is not identity
**Observed through:** overlapping Jin/Ryota child-history memories and recurring concepts across project generations.
**Changed:** version lattice, identity audit, project-generation separation.
**Prevents:** false merges across characters or rewrites.

## L-005 — Mystery cannot replace movement
**Observed through:** the user's own recognition that mystery/depth can improve while clarity and pacing lag.
**Changed:** creative review criteria emphasize progression, causality, scene purpose, information flow, rhythm, and emotional movement.
**Prevents:** using lore density as a substitute for narrative motion.

## L-006 — Protect established constraints
**Observed through:** repeated image/cover and artifact revisions where preserving existing composition and unrelated elements mattered.
**Changed:** protected-element discipline in creative artifact work.
**Prevents:** regressions caused by unrelated edits.

## L-007 — Complexity must earn its place
**Observed through:** repeated technical/agent architecture exploration where conceptual ambition could expand faster than practical need.
**Changed:** idea -> prototype -> minimum working system -> stable system -> expansion framing.
**Prevents:** infrastructure maximalism before requirements justify it.

## L-008 — Preserve the failure path
**Observed through:** archive corrections and architectural reversals where understanding why an approach failed was more useful than keeping only the replacement.
**Changed:** negative knowledge and knowledge-state transitions became durable layers.
**Prevents:** repeating the same mistakes under new wording.

## L-009 — Canon and analysis must remain separate
**Observed through:** imperial scale, power-system consequences, and cosmological relations repeatedly producing valid analytical consequences that were not explicitly established.
**Changed:** derived/inferred/speculative statuses and explicit ownership boundaries.
**Prevents:** logical implication being mistaken for fictional law.

## L-010 — Relationships deserve first-class status
**Observed through:** Jin/Ryota, Almont/son, Adam/Jin, empire/Dark Forest, and cross-project concept relationships carrying more meaning than isolated entity summaries.
**Changed:** relationship matrix, causal maps, propagation rules.
**Prevents:** preserving endpoints while losing the structure that gives them meaning.

## Meta-lesson
A durable lesson should remain linked to the evidence pattern that produced it. When future work contradicts a lesson, update the lesson's confidence or scope rather than silently preserving it as universal law.
