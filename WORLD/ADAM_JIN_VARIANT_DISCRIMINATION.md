# Adam ↔ Jin Variants — Identity Discrimination

## Core memory
Adam is remembered as a traveler between worlds and a follower of Jin. Because Jin exists in multiple remembered iterations/versions, Adam becomes a potentially decisive observational anchor.

## Why Adam is important to version recovery
A character who repeatedly travels between worlds can provide continuity across settings. If Adam appears across multiple Jin variants, historical scenes may reveal whether:

- Adam recognizes each as the same Jin;
- Adam recognizes differences immediately;
- Adam uses different names/titles;
- Adam knows that versions exist;
- Adam's own memories persist across world transitions;
- Adam's loyalty attaches to a person, an identity, an idea, or a role.

None of these are established canon yet.

## Four identity models
### Model A — one Jin across variants
Adam recognizes one underlying identity despite different incarnations.

### Model B — separate Jins
Adam treats each as a distinct person.

### Model C — partial continuity
Memory or identity persists unevenly between versions; Adam may recognize an essence while not sharing the same history.

### Model D — Adam is not aware
Different versions may appear unrelated to Adam unless the narrative explicitly reveals the connection.

## Recovery evidence
Search future transcripts for scenes where Adam:
- meets Jin after a world transition;
- calls Jin by a specific name/title;
- reacts to a changed appearance/personality;
- refers to events that another version should not know;
- compares one Jin to another;
- demonstrates memory across worlds;
- follows Jin despite changed circumstances;
- refuses Jin or disagrees with him;
- explains why he follows him.

## Character depth test
Adam must not be reduced to "follower" merely because that is the currently remembered role. A follower can still have independent desire, judgment, fear, loyalty, resentment, or a personal reason for following.

The strongest future scenes to recover are therefore not exposition about Adam, but moments where his actions differ from what Jin expects.

## Canon boundary
This file defines an investigation model. It does not establish any identity mechanics for Jin variants.
