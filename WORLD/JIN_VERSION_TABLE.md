## Why an empty table is preferable to fabrication
A version registry has unusually high error propagation. If two versions are incorrectly merged, every later relationship, power, chronology, and scene can become contaminated. It is therefore better for an entry to remain unknown than to contain a plausible false identity.

## Required evidence for promotion
A version should receive a permanent identity when a source gives enough local context to distinguish it from another version through at least one strong discriminator:
- different project/world;
- explicit variant label;
- incompatible history;
- distinct origin;
- distinct personality;
- distinct physical/visual identity;
- explicit temporal relationship;
- explicit statement that it is another/alternate Jin.

## Cross-version comparison
Once two versions are recovered, compare:
- invariant traits;
- altered traits;
- memory continuity;
- ontological status;
- power scope;
- relationship network;
- narrative function;
- ending/fate;
- reason for divergence.

## Rule
Do not fill this table from broad summaries alone when the summary itself warns that variants are unresolved.
