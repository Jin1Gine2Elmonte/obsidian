# Memory Reconstruction Layer — World of Jin

## Purpose
This layer sits between remembered summaries and canonical worldbuilding. Its job is to extract information that is genuinely present in the accessible memory while making the structure of that memory visible.

## What the current memory actually contains
The accessible corpus is uneven. It is unusually strong in broad anchors and structural relationships, but much weaker in scene-level dialogue, exact chronology, variant registries, and fine mechanical rules.

### Strongest remembered clusters
1. Jin as a recurring meta-fictional/cosmic anchor.
2. Multiple Jin versions/iterations.
3. Almont as emperor and tyrannical father/authority.
4. Arisa as Almont's wife and a pivotal death event.
5. Ryota as Almont's son with rebellion, departure, and return.
6. Garthin as a contradictory ruler.
7. Adam as a world traveler and Jin follower.
8. Empire with approximately 1,060 military cities and enormous city populations by fictional scale.
9. Dark Forest as a major limit on imperial control.
10. Magic, inherited Powers, and a spiritual-vessel concept.
11. Existence Sublime, Entity of Forgetting, Primordial Rift, Shadows of the First Creation, and related cosmological anchors.

## Hidden density inside each cluster
The summary-level statement "Ryota rebels against Almont" contains several latent dimensions that should not be discarded:
- relationship state;
- political role;
- geographic movement;
- succession pressure;
- emotional estrangement;
- temporal repetition;
- identity formation;
- connection to Arisa's death;
- possible relationship to the separate Jin-labeled child-history thread.

Likewise, "Adam follows Jin" contains at least:
- loyalty type;
- world access;
- information transfer;
- memory continuity;
- variant recognition;
- autonomy;
- reason for following;
- possible bridge between otherwise distinct worlds.

## Memory asymmetry
Different concepts have different preservation quality.

### High preservation
- broad Jin premise;
- broad Almont/Ryota family pattern;
- existence of multiple Jin versions;
- empire scale;
- Dark Forest boundary;
- Magic/Powers distinction;
- Garthin contradiction;
- Adam traveler/follower role.

### Medium preservation
- political implications;
- capital's significance;

- relationship architecture;

### Low preservation
- exact scenes;
- dialogue;
- ages;
- dates;
- exact mechanisms;
- exact motives;
- detailed geography;
- named Jin variant catalog;
- detailed Garthin/Adam relationships;
- exact cosmological hierarchy.

## Most important inference about the archive
The present memory should not be treated as a miniature version of the full conversations. It is better understood as a **compressed map of high-salience residues** from many conversations.

That means a repeated fact may be important because it survived compression, while a missing detail may have existed historically but not survived into current accessible context.

## Recovery implication
Future transcript imports should compare themselves against this layer and ask:
- what is genuinely new?
- which old uncertainty is resolved?
- which supposed certainty is contradicted?
- which relationship becomes explicit?
- which version receives ownership of a previously generic fact?
- which event explains a previously isolated state?

## Anti-invention rule
Never use the existence of a blank field as evidence that the missing answer has a particular shape. A gap is not a clue unless the surrounding source material supplies one.

## Strategic principle
The highest-value recovery target is not whatever is easiest to summarize. It is whatever, once recovered, changes the largest number of existing nodes correctly.

Current highest-impact candidates:
- Jin/Ryota identity;
- exact Jin variant genealogy;
- Arisa death and immediate aftermath;
- first/defining Almont-child confrontations;
- Adam/Jin origin and variant recognition;
- Garthin's defining scenes;
- actual power limitations;
- actual Dark Forest mechanism;
- explicit bridge between human and cosmic layers.
