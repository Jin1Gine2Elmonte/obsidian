## Core preservation rules
1. Never collapse different Jin versions into one merely because they share a name.
2. Never turn derived worldbuilding implications into canon.
3. Preserve family events in chronological order when dates/ages become available.
4. Preserve contradictory historical states instead of erasing them.
5. Link personal events to political consequences where the original material establishes such consequences.
6. Prefer scenes and dialogue when recovering character psychology.
7. Treat every new node as a hypothesis about structure until supported by source evidence.

## Priority rule
When historical transcripts become available, a decisive scene or direct user statement outranks pages of elegant synthesis. Update the smallest relevant node, then propagate the change through relationships and timeline.
