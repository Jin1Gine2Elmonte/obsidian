# Jin Variants — Version Registry Framework

## Why this exists
The user's fictional history contains references to multiple versions/iterations of Jin. Treating every occurrence as one character risks destroying chronology and creating false canon. This file is therefore a registry of version identity, not a forced unification.

## Confirmed baseline
The accessible memory supports multiple Jin/Gin/Gene iterations or variants, but does not expose a complete authoritative catalog of their names and differences.

## Required record for every variant
For each recovered version, record:
- canonical name
- alternate spelling/name
- project/world
- first known appearance
- role
- age/stage if relevant
- personality
- memories retained
- awareness of fiction
- powers
- limitations
- relationships
- cosmological status
- chronology
- visual identity
- defining trauma/event
- what distinguishes this version from the nearest variant
- what later replaced/changed it
- source conversation/artifact

## Classification model
Possible relationships between versions should not be assumed. When recovered, classify as one of:
- alternate universe
- timeline branch
- rewrite
- reincarnation
- incarnation/avatar
- parallel self
- historical iteration of the same fictional concept
- separate character sharing a name
- unknown

## Invariant search
The deeper question is not only "how many Jins?" but "what remains Jin across versions?" Candidate invariant dimensions to investigate:
- relationship to imagination
- relationship to fiction/reality
- reality-level agency
- treatment of choice
- relationship to other worlds
- role as creator/observer/participant
- recurring emotional core

These are investigation axes, not established invariants.

## Divergence map
Future recovered conversations should create entries like:

`JIN-V001 -> JIN-V002`

with:
- changed elements
- preserved elements
- reason for change
- date/phase
- evidence
- whether the change is canon or draft.

## Anti-conflation rule
Never combine two versions simply because they share a name, power, or theme. Shared properties are evidence for a relationship, not proof of identity.

## Recovery targets
Search historical material for phrases involving:
- Jin / Gin / Gene
- version
- copy
- clone
- alternate
- original
- first Jin
- another Jin
- future Jin
- past Jin
- different world
- rewritten
- reincarnation
- avatar
- reality control
- fictional awareness

Then capture surrounding context rather than isolated keyword hits.
