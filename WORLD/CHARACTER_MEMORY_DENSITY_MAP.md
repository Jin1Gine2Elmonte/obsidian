# Character Memory-Density Map

## Purpose
This map ranks characters by the kind of knowledge currently preserved, not by importance alone. It prevents a broad label from being mistaken for a complete biography.

## Jin
### Strong memory
- recurring cosmic/meta-fictional anchor;
- connection to imagination;
- fictional-awareness premise;
- extraordinary reality control;
- multiple versions/iterations.

### Medium memory
- human-scale/cosmic tension;
- possible relation to Almont/Ryota branch;
- Adam as follower/traveler connection;
- broader cosmological adjacency.

### Weak memory
- exact variant registry;
- exact motivations;
- exact limitations;
- precise chronology;
- scene-level dialogue;
- exact relationships in every project.

## Almont
### Strong memory
- emperor;
- tyrannical ruler;
- husband of Arisa;
- father of Ryota in the strongest family branch;
- adviser Benjamin.

### Medium memory
- capital-centered authority;
- family/political overlap;
- repeated conflict with son;
- institutional scale of empire.

### Weak memory
- detailed ideology;
- specific policies;
- exact reactions to Arisa's death;
- detailed relationship with Benjamin;
- full reign chronology.

## Ryota
### Strong memory
- Almont's son;
- Arisa-related traumatic rupture;
- escape;
- sustained rebellion;
- repeated departure/disappearance;
- eventual return to capital because position/future influence matters.

### Critical uncertainty
Relationship to the separate Jin-labeled child-history thread.

## Arisa
### Strong memory
- Almont's wife;
- mother figure in the family branch;
- death is a pivotal rupture.

### Weak memory
Almost everything about her living personality, politics, relationship dynamics, and death circumstances.

## Benjamin
### Strong memory
- adviser associated with Almont.

### Weak memory
Motives, methods, loyalty, political influence, secrets, relation to family.

## Garthin
### Strong memory
- ruler;
- brutal/violent;
- hidden or difficult-to-explain kindness;
- contradiction is central to characterization.

### Weak memory
Exact world placement, chronology, relationships, powers, defining scenes, origin, ending.

## Adam
### Strong memory
- travels between worlds;
- follows Jin.

### Medium memory
- potential bridge between settings and Jin variants.

### Weak memory
Origin, motives, travel mechanism, autonomy, memory continuity, exact relationship with Jin.

## Strategic meaning
The archive should not distribute equal detail across characters merely to make the documents look balanced. It should preserve the actual asymmetry of remembered information. High-density nodes should receive detailed reconstruction; low-density nodes should remain visibly sparse until source material fills them.
