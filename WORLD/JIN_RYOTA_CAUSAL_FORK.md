# Jin / Ryota — Causal Fork Model

## Purpose
The identity ambiguity is not merely a naming problem. It creates two different possible causal structures for the entire Almont branch.

## Fork A — Jin = Ryota
If later evidence confirms identity, the following chain becomes one biography:

Arisa's death -> childhood trauma -> escape -> return to capital -> rebellion against Almont -> repeated departure/return cycles -> political influence -> later cosmological/meta-fictional role.

Consequences:
- Almont becomes directly embedded in Jin's formative history.
- The empire becomes part of Jin's emotional origin rather than a separate setting.
- Adam's relationship to Jin potentially inherits the imperial history.
- Jin's later cosmic agency contrasts with a childhood defined by inability to control a decisive human event.
- The transformation from powerless child to reality-level actor becomes potentially central to the character architecture.

None of the final links above are canon until the identity is confirmed.

## Fork B — Jin != Ryota
Then the world contains at least two distinct major axes:

### Ryota axis
Arisa -> childhood rupture -> escape -> return -> rebellion -> imperial succession/identity conflict.

### Jin axis
Imagination -> fictional awareness -> reality-level agency -> interworld/cosmological role.

Consequences:
- The Almont family remains a human/political storyline separate from Jin's cosmic storyline.
- Similarities between the two characters become a possible thematic mirror rather than shared biography.
- The archive must prevent accidental transfer of scenes, powers, or relationships.

## Fork C — project-generation rewrite
A third possibility is that an earlier version used one identity while a later rewrite renamed/restructured the same narrative role. In that case both records are historically true but only one is current canon for a given project generation.

## Diagnostic questions
1. Is Jin ever explicitly called Almont's son?
2. Is Ryota ever described as aware of fictional existence?
3. Does either name occur in the same scene?
4. Are their ages compatible?
5. Do they share appearance, personality, powers, and chronology?
6. Does the user's wording indicate a rewrite or replacement?
7. Which project title contains the family branch?
8. Which project title contains cosmic Jin?
