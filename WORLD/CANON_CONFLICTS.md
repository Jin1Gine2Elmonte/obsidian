# Canon Conflicts — Active Audit

## Purpose
Track places where the current accessible memory contains incompatible or potentially cross-project statements. Conflicts are preserved instead of harmonized by force.

## C1 — Jin vs Ryota in the Almont child-history
One memory thread labels the child/son witnessing Arisa's death as Jin; another labels Almont's son as Ryota with an extremely similar sequence. This is the highest-impact identity conflict currently visible.

State: UNRESOLVED.

Required evidence:
- explicit equivalence;
- simultaneous appearance of Jin and Ryota;
- different ages/events;
- project/version markers;
- direct correction by the user.

## C2 — Cosmic Jin vs imperial-family branch
Jin is also remembered as a cosmic/meta-fictional actor. It is unknown whether this is the same incarnation, a later rewrite, or a separate project generation from the imperial child-history.

State: HYPOTHESIS SPACE.

## C3 — Garthin plot connectivity
Garthin is strongly remembered as a ruler with a contradiction between brutality and hidden kindness, but direct links to Jin, Almont, or Adam are not sufficiently preserved.

State: CHARACTER CANON / RELATIONSHIP UNKNOWN.

## C4 — Cosmology cross-project membership
Existence Sublime, Entity of Forgetting, Primordial Rift, Shadows of the First Creation, and Strings of Fate are all durable creative anchors, but thematic proximity is not proof that they inhabit one canonical universe.

State: PROJECT MEMBERSHIP REQUIRES EVIDENCE.

## C5 — Power-system mechanics
Magic, inherited Powers, and spiritual vessel are confirmed concepts, while most detailed mechanics remain missing.

State: PARTIAL CANON.

## Resolution protocol
When conflict evidence appears:
1. preserve the old record;
2. attach source/date;
3. classify the conflict;
4. determine the current state;
5. propagate only verified changes;
6. keep obsolete interpretations available as history when useful.
