# Canon Quality Tests

A major worldbuilding statement should pass these tests before being treated as durable canon.

## Identity test
Which exact character/version/project does this statement belong to? A shared name is not enough.

## Source test
Is the statement directly established, repeated consistently, inferred, or speculative?

## Temporal test
Is it current, historical, superseded, abandoned, or undated?

## Causal test
What event caused it? What did it cause afterward?

## Relationship test
Which other entities change because this statement is true?

## Scene test
Can a concrete scene or dialogue support it? If yes, link the evidence.

## Constraint test
What can no longer happen if the statement is canonical? A useful world rule creates constraints.

## Negative-rule test
What can the character/system/world NOT do? Negative rules often reveal more structure than ability lists.

## Scale test
Does a large-number claim have institutional consequences, and have those consequences been separated from recovered facts?

## Version test
Would this statement remain true for all versions? If not, attach it to the correct version.

## Propagation test
If this statement changes, which notes must be rechecked?

## Compression test
Does the summary preserve why the fact matters, not just what it says?

## Anti-hype test
Would the statement still be considered valuable if the dramatic language were removed? If not, it may be description rather than knowledge.
