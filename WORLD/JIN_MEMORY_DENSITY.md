# Jin — Memory-Density Extraction

## Purpose
This note consolidates the strongest currently accessible memory about Jin while explicitly separating established material from interpretations and retrieval targets. It exists because Jin has accumulated many representations across projects and should not be flattened into one generic character.

## High-confidence recurring core
Jin/Gin/Gene is a recurring cosmic/meta-fictional anchor. The central remembered premise is that imagination can function as a realm/place that lacks ordinary physical existence while still exerting influence on human reality. Jin is associated with awareness of fictional existence and extraordinary reality control.

The important distinction is that his importance is not merely numerical power. His presence destabilizes ordinary assumptions about character, author, fiction, reality, causality, and choice.

## Meta-fictional tension
A useful recurring structural tension is:

Jin can potentially control reality, yet narrative significance depends on what he does not simply erase.

This is an analytical lens, not established canon. Historical scenes should determine whether it actually applies.

## Characterization pressure points
When extracting scenes, search for:
- moments where Jin refuses to use power
- moments where he uses power and pays a price
- moments where awareness of fiction changes behavior
- moments where another character perceives Jin differently
- moments where Jin fails emotionally despite succeeding cosmically
- moments where a version of Jin contradicts another version
- moments where Jin's relationship with choice is explicitly discussed

These observations can reveal the character's actual architecture better than a generic power list.
