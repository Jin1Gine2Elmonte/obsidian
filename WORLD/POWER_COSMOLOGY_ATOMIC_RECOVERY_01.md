# Power + Cosmology Atomic Recovery — World-System Memory

## Status
Partial atomic recovery. This file is a **recovery map and evidence-oriented memory layer**, not a canonical mechanics file.

## Why this layer exists
The accessible memory preserves several high-impact distinctions, but not enough source-level mechanics to justify a reconstructed ruleset. The goal is therefore to preserve the smallest stable units that future historical conversation extraction can attach to exact project/version context.

## Power-system atoms currently recoverable

### P1 — Magic exists as a distinct capability class
- Magic is remembered as operating beyond ordinary logic.
- It should not be reduced automatically to another combat technique tree.
- Exact acquisition, mechanics, costs, and limits remain unresolved.

### P2 — Powers exist as a separate class
- Powers are remembered as more logically constrained than Magic.
- Powers may be inherited through blood.
- This links supernatural capability to lineage, identity, succession, status, and politics.
- Exact inheritance rules remain unresolved.

### P3 — Spiritual vessel exists as a distinct concept
- A spiritual-vessel concept is part of the remembered worldbuilding.
- Its ontology is not yet recovered with source-level certainty.
- Do not assume whether it is physical, spiritual, symbolic, metaphysical, or some combination.

### P4 — Power is a social/political architecture, not only combat
The remembered structure implies a strong conceptual connection among:
`blood -> inheritance -> identity -> status -> succession -> political authority`
This is a structural interpretation supported by the preserved distinction, but exact institutions remain unrecovered.
