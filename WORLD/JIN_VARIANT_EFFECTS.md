# Jin Variant Propagation — How a Version Change Alters the World

## Purpose
A change to Jin should never be treated as a local character edit when Jin is structurally connected to multiple layers of the setting. This file defines what must be re-audited whenever a Jin variant is corrected, replaced, split, or merged.

## Propagation domains

### Identity
Re-check:
- name and aliases;
- age/stage;
- origin;
- memories;
- fictional awareness;
- relationship to other variants.

### Family
If the affected version belongs to the Almont branch, re-check:
- father relationship;
- Arisa relationship;
- Ryota identity;
- inheritance;
- chronology of escape/return;
- reason for rebellion.

### Political world
Re-check whether the version changes:
- status in the empire;
- succession;
- reason for returning to the capital;
- influence over others;
- relationship with military or court institutions.

### Power system
Re-check:
- reality control;
- inherited Powers;
- Magic;
- spiritual vessel;
- world-travel capability;
- limits and costs.

### Cosmology
Re-check relationships with:
- imagination;
- Existence Sublime;
- Entity of Forgetting;
- Primordial Rift;
- Shadows of the First Creation;
- broader creation/reality concepts.

### Relationships
Re-check every major edge rather than assuming it survives the version change:
- Adam;
- Almont;
- Ryota;
- Arisa;
- Garthin;
- other Jin variants;
- institutions.

## Propagation rule
A version change should trigger updates to:
1. the variant lattice;
2. canonical status;
3. timeline;
4. affected relationship edges;
5. causal map;
6. scene index;
7. project membership;
8. high-level memory synthesis.

## Why this matters
Without propagation, an archive can contain internally incompatible files that each appear correct in isolation. Version-aware propagation keeps the knowledge graph coherent.

## Canon boundary
This is an archive operation rule, not a claim that every domain actually changes whenever Jin changes. Only evidenced dependencies should be propagated as factual changes.
