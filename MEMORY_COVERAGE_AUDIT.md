# Memory Coverage Audit — What Has and Has Not Reached the Vault

## Purpose

This document is a **coverage map**, not a claim that the vault now contains the user's complete history.

The archive has undergone substantial structural engineering and multiple context-recovery passes. Several high-impact owners have now been deepened, but a large amount of durable conversational knowledge still requires historical extraction.

The central distinction remains:

`accessible memory/context` ≠ `knowledge already represented in Obsidian` ≠ `raw historical conversation evidence`.

A topic listed here may be known in current context while still being absent, underdeveloped, compressed, or unsupported by original transcript evidence in the repository.

## Coverage status vocabulary

- **PRESENT** — meaningful dedicated representation already exists.
- **PARTIAL** — some knowledge exists, but important detail/relations/history are missing.
- **SHALLOW** — represented mainly as a label or summary; substantial underlying memory is not captured.
- **UNREPRESENTED** — known in accessible context but not meaningfully represented in the vault.
- **RAW-EVIDENCE NEEDED** — current memory exists, but reliable reconstruction requires historical conversation/source material.

## XX. The most important missing layer: raw conversations

Status: RAW-EVIDENCE NEEDED.

No amount of architectural refinement can substitute for the original conversation record.

The definitive reconstruction target is:

`conversation -> message -> local context -> project/version -> entity -> relationship -> event -> decision -> evidence status -> later change`

Only this layer can recover details that were compressed out of current memory summaries.

## Critical truth

The current vault should **not** be described as a complete copy of the user's conversational memory.

It is a rapidly improving **external memory architecture containing a partial reconstruction**.

The recovery passes have increased the amount of preserved durable context, but the highest-value unresolved work is still historical extraction and integration into the correct owners.

## Coverage principle

A domain is not considered recovered because it has a file.

A domain becomes recovered when its important entities, relationships, events, decisions, evolution, rejected paths, and source evidence are represented to the degree justified by available history.
