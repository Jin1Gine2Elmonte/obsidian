# Project & Idea Timeline

## Purpose
A reconstructed high-level sequence of project evolution. This is **not** a verbatim transcript timeline. Ordering without direct dates is approximate and must not be treated as exact chronology.

## Temporal governance
Use the dedicated temporal owners when interpreting or extending this timeline:
- `TEMPORAL_MODEL.md` — separates conversation, project, and fictional/world time.
- `TEMPORAL_EVENT_TYPES.md` — defines world, project, and knowledge events and their identity.
- `KNOWLEDGE_STATE_TRANSITIONS.md` — records changes in what the archive knows or believes.
- `PROJECT_STATE_TRANSITIONS.md` — records project-generation/state changes rather than fictional chronology.

This file remains the broad chronology/navigation surface; it does not replace those specialized temporal/state owners.

## Temporal evidence labels
- `DATED` — explicit date/source available.
- `ORDERED` — sequence is supported, but exact date is unavailable.
- `APPROXIMATE` — broad placement inferred from available context.
- `UNKNOWN` — temporal placement cannot currently be established.

## 1. Early fiction development — `APPROXIMATE`
- Developed dark fantasy and cosmological fiction centered on Jin/Gin/Gene and a reality/imagination premise.
- Built major empire/family material around Almont, Arisa, Benjamin, Ryota, and the Dark Forest.
- Developed a distinction between Magic and inherited Powers and introduced the spiritual-vessel concept.
- Developed recurring cosmological anchors such as Abyss, Corruption, Curse of the Ancients, Existence Sublime, Entity of Forgetting, Primordial Rift, and Shadows of the First Creation.

Temporal caution: the archive does not currently contain enough source-level dates to prove that every listed cosmological anchor was introduced in the same phase or project generation.

## 2. Novel architecture phase — `APPROXIMATE`

- Explored a 20-chapter main-novel structure.

## Temporal integrity rules
1. A later file is not automatically later in-world chronology.
2. Repository commit order is not fictional chronology.
3. A summary's ordering is weaker evidence than a dated transcript.
4. Similar events in different project generations must not be merged by chronology alone.
5. When a source revises a prior state, preserve the transition rather than silently rewriting history.
