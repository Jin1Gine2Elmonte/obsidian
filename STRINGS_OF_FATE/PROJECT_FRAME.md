# أوتار القدر — Project Frame

## Current knowledge level
The archive confirms the title and a substantial visual/cover-art specification. The wider narrative canon is intentionally left open where it has not been explicitly established in the available context.

## Core question space
The project name naturally opens a system of questions that should be investigated only as hypotheses until canonized:

- What does a "fated string" represent: possibility, causality, identity, memory, consequence, relation, or something more abstract?
- Does a string connect a person to another person, to an event, to an outcome, to a place, to a version of self, or to an entire causal structure?
- Is fate an imposed external structure or an emergent property of choices and relationships?
- Are strings visible because fate has become perceptible, or because the observer has changed?
- Can strings be cut, crossed, tied, transferred, hidden, duplicated, or only interpreted?
- What is the cost of interacting with them?
- Can a person escape fate by breaking a string, or does breaking it generate another form of causality?
- Can two apparently contradictory fates coexist?
- Is the string a representation of fate or is it fate itself?
- What happens when a string belongs to something that does not exist?

These are **question nodes**, not canon.

## Thematic axes
Potential thematic axes for future development:

### Fate vs agency
The strongest version of the project should avoid reducing the conflict to a simple "free will defeats destiny" structure. More interesting possibilities include agency operating inside deterministic structures, choice altering the meaning rather than existence of an outcome, or fate emerging from repeated decisions.

### Relation vs isolation
A string is inherently relational. This suggests a project architecture in which identity is partially defined by connections rather than by isolated individuals.

### Knowledge vs intervention
Seeing a fate does not necessarily grant the ability to change it. Knowing an outcome can itself become a causal force.

### Prediction vs interpretation
A string can be legible while its meaning remains ambiguous. This provides a way to preserve mystery without withholding all useful information.

### Cost of severance
Any future rule allowing strings to be altered should specify what is lost, displaced, inherited, or created by the act.

## Narrative architecture candidates
Possible large-scale narrative structures include:

1. Discovery: the protagonist first perceives the strings and initially misinterprets them.
2. Mapping: patterns reveal relationships that contradict ordinary understanding.
3. Intervention: attempts to alter one thread produce indirect consequences.
4. Reinterpretation: the protagonist realizes that the visible string is not the whole causal structure.
5. Convergence: multiple apparently independent threads resolve around a shared hidden event or choice.

These remain candidate structures, not established plot.

## Mystery discipline
The project should preserve unresolved questions deliberately. Mysteries should create pressure through partial understanding rather than through arbitrary omission. Every major revelation should answer one question while opening a deeper one only when structurally justified.

## Project expansion rule
When future conversation provides actual story content, add it here and to the appropriate dedicated node. Never retroactively promote a brainstorming hypothesis to canon merely because it was written in this file.
