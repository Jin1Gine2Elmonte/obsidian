## Explicit remembered visual requirements

1. The strings are semi-transparent / translucent white.
2. Their emitted light has a slight light-emerald / pale-green tint.
3. They must not become plainly green strings.
4. Their glow must not alter the sky's color.
5. The overall composition must remain intact.
6. The city must remain intact.
7. The character must remain intact.
8. Existing scene lighting must remain intact.
9. Existing color relationships must remain intact.
10. Existing title typography/font must remain intact unless explicitly requested otherwise.
11. Unwanted writing at the bottom should be removed.
12. The decorative treatment beneath the title should be improved.
13. The original image dimensions should remain unchanged.
14. The final polish should reduce the feeling of a generic AI-generated image.

## What the user emphasized

The important distinction was not “make the strings green” but: **white / transparent strings whose light leans slightly toward light green**.

The sky was explicitly protected from that color shift.

The user also emphasized that no other element should be casually changed. The task was an exact transformation, not a redesign.

## Derived design implications — NOT canonical facts

These are implementation implications inferred from explicit requests, not claims about story canon:

- String opacity should vary according to depth rather than be uniformly transparent.
- Glow intensity should not be identical across all strings.
- Light should appear integrated with the scene rather than as a flat overlay.
- Intersections should preserve visual hierarchy.
- The strings should retain a delicate, ethereal material quality.
- The pale-green effect should behave as illumination, not a global recoloring filter.
- The sky should be isolated from the string color treatment.
- Changes unrelated to the requested elements are regressions.
