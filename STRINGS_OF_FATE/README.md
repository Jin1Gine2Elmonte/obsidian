# أوتار القدر — Strings of Fate

## Purpose

This directory is the dedicated knowledge domain for the creative project **أوتار القدر / Strings of Fate**. It should become the authoritative place for every durable piece of information related to the project: identity, premise, characters, world, themes, symbolism, visual language, cover art, chronology, narrative architecture, unresolved questions, and future revisions.

## Known canonical visual direction

The cover direction established in prior work is unusually constraint-sensitive:

- The strings must read as **semi-transparent white luminous threads**.
- Their glow should lean subtly toward **light emerald green** rather than becoming strongly green.
- The strings must not contaminate or recolor the sky.
- Existing composition should remain intact.
- Existing city should remain intact.
- Existing character should remain intact.
- Existing lighting logic should remain intact.
- Existing overall color relationships should remain intact.
- Existing title/font treatment should remain intact unless a specific later instruction changes it.
- Unwanted writing at the bottom should be removed.
- Decoration beneath the title should be improved.
- The original dimensions/aspect ratio should be preserved.
- The final image should feel artistically polished rather than generically AI-generated.

## Project principle

A change to one visual component must not silently rewrite the visual identity of the whole cover. Preserve the established composition first; innovate inside the permitted degrees of freedom.

## Canon discipline

Do not invent project facts merely because this directory exists. Unknown material must remain marked as unknown, speculative, or pending confirmation. When later conversation establishes canon, update the dedicated node and preserve the prior state when historically useful.
