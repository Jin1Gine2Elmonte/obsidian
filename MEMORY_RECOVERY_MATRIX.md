# Memory Recovery Matrix — High-Impact Historical Reconstruction

## Purpose
This matrix converts the broad coverage audit into a recovery strategy. It does not claim that historical conversations have already been recovered.

The governing distinction is:

`known in current context` != `represented in the vault` != `supported by raw conversation evidence`.

The objective is to recover the largest amount of meaningful knowledge with the fewest false merges and the least redundant writing.

## Recovery unit

The preferred atomic recovery unit is not a topic summary. It is:

`source message/scene -> local context -> entity/version -> project -> claim -> relationship -> event -> decision -> evidence status -> later revision`

One recovered unit may populate several graphs, but its source is stored once.

## Anti-loss rule

Do not discard a recovered detail because it looks small. First classify it as one of:
- unique fact;
- relation;
- event;
- decision;
- constraint;
- evidence;
- historical change;
- rejected path;
- terminology/name;
- visual/audio artifact;
- workflow lesson.

Small details become valuable when they connect otherwise isolated nodes.

## Anti-fabrication rule

Never fill a missing historical scene from:
- logical expectation;
- genre convention;
- later summary wording;
- a different project;
- a different Jin version;
- a thematic parallel.

Keep missing material explicitly missing until source evidence appears.

## Completion test

A recovery domain is considered meaningfully recovered only when it has, as applicable:
- entities;
- relationships;
- events/scenes;
- motives/decisions;
- chronology;
- evolution;
- rejected paths;
- evidence/provenance;
- current status;
- known gaps.

## Current strategic conclusion

The archive architecture is now strong enough that the next meaningful increase in quality should come primarily from **historical extraction**, not further proliferation of governance files.

When raw historical conversations become available, begin at P0 and propagate every verified discovery through the existing ownership graph.
